Step-by-step free hosting guide for Lanh UN

Option 1: Deploy on GitHub Pages

  2. Create a new repository named lanhun.github.io

  4. Go to **Settings** -> **Pages** -> Select **Main Branch** as source and click **Save**

  2. Click **Add New Project** and select your portfolio repository
  3. Click **Deploy** — Vercel provisions instant SSL and live URLs automatically!

  2. Drag and drop the folder containing index.html into the upload area
  3. Your website will be instantly published in 5 seconds!
